## 同样的“裸金属”，为什么报价能差 30 倍

把三份报价摆在一起就看出问题了。每月 $55 的 Ryzen 5 7600 带 10Gbps 不限流量端口；每月 $126 的 Xeon E3-1230 v1 只带 30TB 月流量，想要 1Gbps 不限流量端口得从 $159 起，10Gbps 不限流量要 $499 起；每月 $80 的 E3-1230v3 带的是 30M CN2 端口。

30M 到底有多大？GigeNET 给过一个换算基准：30TB 月流量约等于 93Mbps 持续跑满一个月，1Gbps 端口跑满 30 天约 324TB。按同样的算法，30Mbps 端口满打满算一个月约 9.7TB。图片站和视频源站两周就能吃完，API 和后台系统一个月都用不掉一半。

价差的另一半在 CPU。E3-1230 同时出现在三家入门位：LightLayer $56 起、SellBGP $80 起、GigeNET $126 起。同一颗处理器，差价来自端口、线路、机房和 IP 数量，跟算力关系不大。贵的那台要先问清楚贵在哪，否则多付的钱可能只买到一个更靠东海岸的机柜。
